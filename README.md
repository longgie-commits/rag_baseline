# RAG 学术级评估基线项目 (RAG Evaluation Baseline)

本项目是一个专注于**完全本地化的高级 RAG (检索增强生成)** 演示与对标框架。最新版本已经从一个常规的问答系统，成功进阶为一个完全对标学术界顶级会议标准的**全自动化大模型幻觉与检索评估平台**。

它不仅能在完全脱离商业闭源 API 的情况下从本地知识库回答问题，更能全自动地对自己进行长达数十个维度的严苛自我审判（精确到句法级别的抗幻觉测定与拒答率判定）。

---

## 核心架构大本营

本项目系统由重负载的离线数据链和两个强大的开源语言模型构筑而成：

1. **图情检索器：文本向量模型 (`shibing624/text2vec-base-chinese`)**
   - **作用**：负责把庞大臃肿的参考书籍（如数十万字的教材）切分为精准的文本切片（Chunks），通过 FAISS 持久化数据库转化为数学多维向量。在评测启动时，它负责执行高速最近邻算法找到前 $K$ 个可能相关的切片证据。
2. **知识解码器与严师判卷人：大语言模型 (`Qwen/Qwen2.5-7B-Instruct`)**
   - **作用（其一）：** 作为 RAG 的生成末端。通过接收检索系统找塞回来的相关段落原文和原问题，在显卡算力支持下汇编出人类语言回答。
   - **作用（其二）：** 作为顶层评估框架的 `LLM-as-a-judge`（大模型判卷人）。强行化身毫无感情的学术判裁官，通过提取陈述主张并进行定点 NLI（自然语言推理）比对，冷血地对回答做出幻觉量化和评分。

## 高级学术级测试功能详解 (Advanced Eval Pipeline)

这是本项目最精华的新一代功能，主要由 `src/evaluate.py` 驱动。如果你想复现我们在大模型“拒答防御”以及“幻觉测定”上的实验数据，你绝对不可错过里面的几大精细算法。

> [!TIP]
> **多 K 值自动消融实验 (Ablation Tests over K)**
> 脚本不再是跑一次就完事，它被设计为一个超大外层循环。一次拉起，可连续测定给模型塞入 $k=3, k=5, k=10$ 条检索片段时，它最终发生幻觉频率以及答题精确度的数值震荡。结果会自动输出至 `data/eval_summary.txt`。

> [!IMPORTANT]
> **强硬派指标与自然语言推理混搭核准机制**
> 1. **经典召回率 (Hit@k / MRR)**：系统将直接使用 `benchmark.csv` 已打标好的一字不差的段落金句（Evidence Span），采用底层代码强制逐行匹配检索内容，算出铁证如山的召回得分，剥离“模型发挥差”和“索引其实就没搜到”两层责任。
> 2. **句子切片级幻觉审计 (Claim-level Check)**：彻底取代直接打总分的偷懒操作。通过模型提示词控制先将它自己的回答**逆向拆卸**成数组式的单点陈述短句（Claims），然后分别拿着这些短句与源文档做逐一校验，判定为：`Supported`(有证据), `Unsupported`(完全瞎编-幻觉), 或 `Contradicted`(公然相悖)。

> [!WARNING]
> **细分到毛发级的陷阱防御追踪 (Abstention Matrices)**
> 这 30 题里埋有类似“量子纠缠的卡尔曼极地环境”等彻头彻尾的陷阱题。这套代码具备独立的 Abstention 分类树，能精准出具：
> - 模型到底有没有被忽悠上套而编造胡话（**No-abstention rate / 脱轨作答率**）
> - 抑或是聪明地进行了自保（**Abstention Acc / 拒答防线准确率**）
> - 以及正常题目它也草木皆兵地说不会的乌龙概率（**Over-refusal rate / 过度拒答规避率**）

## 开始评测之旅

如果你的项目基础环境搭建正常，你想要得到那张震撼的评测大盘记录表（时间提醒：全量跑完一次三轮消融测试在 RTX 3060 上这会是一部 30-40 分钟的高压运算“大片”），非常简单：

确保处于当前项目的根目录，虚拟环境处于激活状态下。打开终端：
```powershell
python src/evaluate.py
```
运行结束后，你可以用 Excel 打开 `eval_results.csv` 进行各类图表的拉取和透视分析！
